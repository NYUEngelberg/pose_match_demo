# Pose Match — Live Demo

This repo is the deployed source for the [GLAM-E Lab](https://www.glamelab.org/)'s live demo of **Pose Match**, running at [pose-match.glamelab.org](https://pose-match.glamelab.org).

Pose Match invites visitors to explore open access GLAM collections by striking a pose: a webcam detects the visitor's pose and matches it in real time to an artwork with a similar pose, drawn from the open access collections of the Metropolitan Museum of Art, the Smithsonian Institution, and SMK (Statens Museum for Kunst).

All pose detection happens locally in the browser. User images are never saved or sent anywhere.

## Want to run Pose Match with your own collection?

Don't fork this repo — use the template instead. It contains everything here (minus our analytics) plus a full guide to preparing your own images and deploying for free:

**→ [NYUEngelberg/pose_match_template](https://github.com/NYUEngelberg/pose_match_template)**
